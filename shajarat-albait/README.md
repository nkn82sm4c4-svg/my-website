# شجرة البيت 🌳

> **كل جلسة هادئة تنبت شجرة جديدة 🌱**

لعبة ويب أسرية تشجّع أفراد الأسرة على الجلوس معًا والتحدث وتقليل استخدام الهواتف.
كلما التزم الجميع بالجلسة نمت شجرة ثلاثية الأبعاد أمامهم، وحصلت الأسرة على نقاط ومكافآت، وأُضيفت الشجرة إلى **حديقة الأسرة**.

واجهة عربية بالكامل (RTL)، تعمل على الجوال والكمبيوتر، وشجرة 3D حقيقية (three.js) تنمو مع الوقت.

## التشغيل

```bash
cd shajarat-albait
npm install
npm run dev        # http://localhost:5173
npm run build      # نسخة إنتاج في dist/ — تُرفع على أي استضافة ثابتة
npm run test:e2e   # اختبارات Playwright للرحلة كاملة (CHROMIUM_PATH لاستخدام متصفح مثبت)
```

## التجربة السريعة (وضع العرض Demo)

وضع العرض **مفعّل افتراضيًا** ويظهر شريط واضح أعلى الصفحة طوال تفعيله:

| المدة الحقيقية | في Demo |
|---|---|
| 15 دقيقة | 30 ثانية |
| 30 دقيقة | 60 ثانية |
| 45 دقيقة | 90 ثانية |

وتوقف النمو بعد مغادرة فرد يصبح 6 ثوانٍ بدل 30. أوقفه من زر **Demo** في الأعلى لتجربة الأوقات الحقيقية.
البيانات التجريبية: أسرة «آل سالم» لديها 6 أشجار و160 نقطة (تُستعاد من صفحة حديقة الأسرة).

## رحلة اللعب

`الرئيسية → ابدأ جلسة (الاسم، الرمز، العدد، المدة، بطاقة الحوار، المكافأة) → الانضمام بالرمز → الجلسة الحية → النتيجة → حديقة الأسرة → المكافآت`

- **الانضمام:** رمز من 4 أرقام، إضافة/إزالة أفراد، انضمام بإدخال الرمز، ولا تبدأ الجلسة قبل مشارك متصل واحد.
- **الجلسة الحية:** مؤقت حقيقي، شجرة تنمو (🌱 0% ← أغصان 25% ← أوراق 50% ← كبيرة 75% ← مكتملة 100% مع احتفال)، عداد نقاط، شريط تقدم، بطاقة حوار مع «بطاقة جديدة»، إيقاف مؤقت/استئناف/إنهاء.
- **المغادرة:** زر «مغادرة» لكل فرد (أو إخفاء الصفحة / تبديل التطبيق) ← تنبيه «غادر أحد أفراد الأسرة الجلسة»، توقف النمو 30 ثانية، سقوط ورقة، ويستمر النمو بعد عودة الفرد.
- **النقاط:** 20 لإكمال الوقت + 10 إذا لم يغادر أحد = 30. الجلسات المثالية تُثمر شجرتها 🍎.
- **الحديقة:** كل جلسة = شجرة (5 أنواع). تتطور الحديقة: 10 أشجار أزهار وممر، 25 بركة ومقعد، 50 سياج وفوانيس. مع الإحصائيات (الأشجار، النقاط، الجلسات، الدقائق، أطول جلسة).
- **المكافآت:** مكافآت افتراضية (200 نزهة، 300 فيلم، 500 وجبة، 1000 نشاط كبير)، إضافة مكافآت مخصصة وحذفها، تحديد الهدف، واستلام المكافأة عند الوصول.

## البنية

```
src/
  config/game.ts        كل قواعد اللعبة: المدد، النقاط، توقف المغادرة، مراحل النمو، مستويات الحديقة
  data/                 بطاقات الحوار، المكافآت، الأفراد المقترحون
  game/engine.ts        آلة حالات الجلسة (دوال نقية بوقت صريح) — قابلة للنقل إلى خادم كما هي
  game/rewards.ts stats.ts
  services/             familyService (الطبقة الوحيدة التي تحفظ البيانات) + storage + demoData
  store/                GameContext (الساعة، الحفظ، كشف المغادرة)، ToastContext
  three/                المشهد ثلاثي الأبعاد: treeModel (شجرة إجرائية حسب النمو)، treeScene، gardenScene
  components/  pages/   واجهة React
tests/e2e               اختبارات Playwright
```

**التحويل إلى تطبيق حقيقي:** استبدل دوال `src/services/familyService.ts` باستدعاءات API،
وشغّل `sessionReducer` على الخادم مع WebSocket لمزامنة انضمام الأفراد ومغادرتهم بين الأجهزة — المكوّنات لا تحتاج تغييرًا.

React 19 · TypeScript · Tailwind CSS v4 · three.js · Vite · localStorage
